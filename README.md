## 熊野古道（KUMANO TRAVEL）

| 你想查什么 | 规则 |
| --- | --- |
| 什么时候提交 | [官方公告](https://www.tb-kumano.jp/update/2026/02/25/14564/)：日本时间 07:00–09:30、19:00–22:00；北京时间 **06:00–08:30、18:00–21:00**。这是每日新申请窗口，不是全线统一开售。 |
| 提前多久 | [官方预约指南](https://www.tb-kumano.jp/about/kumano-travel/how-to-book/)要求至少提前 20 天申请。实际可申请日期逐家核对，不给熊野全线统一放票提醒。 |
| 什么时候算订到 | 提交申请后由平台联系住宿。收到安排完成的付款通知后，须在 48 小时内付款，付款后才算确认。 |
| 怎么改期 | 原单通常需取消后重新申请，先核备选房、[原单退改](https://www.tb-kumano.jp/about/kumano-travel/terms-conditions/)及处理时间。消费者平台请出行者本人办理，不视为旅行社团体渠道。 |

住宿入口示例：[小口自然之家](https://www.kumano-travel.com/en/accommodations/koguchi-shizen-no-ie)、[Pilgrims Joe](https://www.pilgrimsjoe.com/%E5%95%8F%E3%81%84%E5%90%88%E3%82%8F%E3%81%9B-inquiry/)。在两个不同渠道查询并不代表房间已被预留。
